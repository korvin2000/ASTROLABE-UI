## Что сделать
1. **Сценарный каркас** в тестах ядра, пакет `io.astrolabe.workflow` (`core/src/test/kotlin/io/astrolabe/workflow/`):
   реальная композиция `Controller` → ячейка → диспетчер → инструменты с поддельным адаптером (найдите, как это уже
   делают существующие сквозные тесты кампании — переиспользуйте их фабрики, не пишите вторую). API каркаса —
   короткий: открыть кампанию на каталоге, отыграть сценарий ответов модели, переоткрыть, принять решение хоста,
   прочитать счётчики и итог. Inject `Clock`/`IdGen`, один `FixedIdGen` на тест.
2. **Фикстура «грязный репозиторий»** (генерируется во временном каталоге в тесте, не коммитится): один коммит
   (несколько отслеживаемых исходников и тест-команда), **нет `.gitignore`**, неотслеживаемый каталог из ≥ 1500 мелких
   файлов (имитация `devtools/`), один файл ≥ 20 МБ; варианты: (а) проверка пишет расходный вывод (`build/…`);
   (б) проверка переписывает отслеживаемый файл данных (`data/notes.json`, WD-14); (в) эксклюзивно заблокированный
   файл (на Windows — открытый без share; на Linux, где блокировки нет, — файл без прав чтения; вариант
   пропускается с явной причиной, если ни то ни другое недоступно). Генерация быстрая: набор WF целиком ≤ 3 мин на
   Windows. Параметр числа файлов (WF-2 сравнивает 300 и 1500).
3. **Постоянные счётчики фаз в телеметрии** (`telemetry/`, плюс точки подсчёта в `os/Git.kt`, `workspace/`):
   процессы git (по границе), файлы и байты прочитанные за захват, объекты записанные за снимок, открытия кампании
   на действие хоста, попытки финализации. Счётчики — данные событий/метрик (видны в событиях), а не логи; без
   wall-clock в идентичности. Новые поля событий — аддитивно; публичный API менять минимально (если меняется —
   `:core:updateKotlinAbi` один раз в конце).

   `docs/`): свойство, страж (класс теста) или `pending P8.W.<n>`, файлы, которые могут его нарушить (по WD из
   диагностики), счётчик. Правило защиты (п. 4 ниже) — в шапке реестра.
5. **Живая задача `real-dirty-repo` в `eval-live`**: по образцу существующих задач `eval-live` (найдите их формат);
   строит ту же фикстуру (≥ 1500 неотслеживаемых файлов, нет `.gitignore`, проверка пишет в дерево) и простую правку
   исходника с тестом. Сеть и живые прогоны в линии **не запускать**; только компиляция `:eval-live:testClasses`
