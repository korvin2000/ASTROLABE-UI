  для словарей; **без** Kotlin `Result` и публичных `value class` (D-08); `io.astrolabe.java` без `suspend`/`Flow`.
- `Clock`/`IdGen` инжектируются; без wall-clock в кэшируемых регионах промпта; тайминги — метаданные, не идентичность.

- Новая зависимость — только если нужна: `gradle/libs.versions.toml` (закреплённая версия), только в модуль-потребитель,

- Worktree ядра не видит соседний SDK: если трогаете или компилируете `provider-ai-gate` — добавляйте

- Второй `FixedIdGen()` в одном тесте конфликтует по первичным ключам SQLite — один на тест.
- `gh` не установлен. **Не печатать URL remote и токены** (в URL remote — токен) в отчёты, логи, коммиты.
- Ключи живых провайдеров — только через стандартное разрешение SDK (окружение / хранилище SDK, как в

## Проверки и расход (§8.4, §8.8 — экономный режим, решение владельца №27)
- L1 — **один раз, когда правка закончена**, а не после каждого цикла правок:
  `./gradlew :core:test --tests '<класс>' -q --console=plain` (классы из карточки). Запускайте фоновой командой или
  суб-агентом t1; в свой контекст берите только сводку: сколько прошло, сколько упало, первые строки падений.
- Тест упал — чините причину и повторяйте только упавший класс. «На всякий случай» ничего не перезапускайте.
- Не больше трёх циклов «правка → тест». Четвёртый не начинать: `БЛОКЕР` в отчёте — что пробовали и что мешает.
- L2 один раз в конце: пакеты из карточки + компиляция зависимых модулей. Полный `./gradlew build` **не запускать**.
- Не перечитывайте и не перепроверяйте собственную работу повторно: её проверит независимый ревьюер, один раз.
- Ничего сверх карточки: без попутных рефакторингов, лишних fixtures и чистки.
- Тесты чинить кодом, не ослаблением тестов; меняете тест — объясните в отчёте почему.
- В отчёте, раздел `## Тесты`: число циклов «правка → тест» и расход токенов, если он вам виден.
