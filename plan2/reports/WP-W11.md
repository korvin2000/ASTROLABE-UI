## Решения (черновые)
- T-03: outline `Other`-файла из чтения захвата (как до W3 атлас разбирал всё) ← вместо: `SymbolIndex.def` пропускает `Other`
  (меняет смысл `def`: общий outline находит строки-имена) → выбрано первое; цена — общий разбор каждого `Other`-файла ≤ 1 МиБ
  на открытии. Безопасная альтернатива: держать outline `Other` только при названном идентификаторе (нужно знать запрос до захвата).
- T-22: `git fast-import` из удержанных байтов ← вместо: свои loose-объекты (обход git CLI) или `hash-object --stdin` на объект
  (N процессов, WF-2) → fast-import (CLI, один процесс, данные дословно). Бюджет 32 МиБ (как T-21 на захват) — 20 МБ файл
  помещается; сверх — поток из блоба со счётом.
- `canonicalise`: дальнейшая память (по каталогам для проверок предков-ссылок) доверяла бы тому, что каталог не стал ссылкой
  между путями прохода (D-47) — не делалось; если нужно ускорять оставшиеся ≈ 24 %, это решение владельца.
