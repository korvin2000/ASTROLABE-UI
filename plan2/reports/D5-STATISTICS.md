**Измеренной точки пересечения нет — только условный прогноз.** Поправка: 16 520 — максимум `api-callers`; у `scenario-1004` максимум loop 15 672, средний пик 13 072; structured/direct — 36 226 / 41 910. Модель: I_L(j) = B_L + b_L(j−1), I_C(j) ≈ H_C; C_L(N) = N[q_L(B_L + b_L(N−1)/2) + p_O·o_L], C_C(N) = N·K_C. Эквивалентный интерцепт loop при калибровке на средний вход — 2 583. Два сценария кэша: постоянная доля (q_L = p_U(1−h) + p_C·h) и постоянный uncached/request (q_L = p_C).

## Формулы и допущения
C_ia = Σ_r cost; A_ia = Σ_r 1(accepted); M_ia = C_ia / A_ia (неудачные попытки в числителе; A = 0 → не определено, не исключается). Парный контраст d_i = ln(X_iB / X_iA), R̂ = e^{d̄}, CI = e^{d̄ ± t(1−α/2, n−1)·s_d/√n}, α = 0,05/3. Цены: C_p = (p_U·U + p_C·C + p_O·O)/10⁶, reasoning внутри output. Мощность: T ~ t_{n−1}(λ), λ = √n·ln(0,8)/s_d. Разложения ΔU = ū·ΔN + N̄·Δu; Δu = (1−h)‾·Δg + ḡ·Δ(1−h). Пересечение: K_a = p_U·u_a + p_C(H_a − u_a) + p_O·o_a; N* = N₀ + 2(K_C − K_L0)/(q_L·b_L); с отношением запросов ρ: N* = N₀ + 2(ρK_C − K_L0)/(q_L·b_L). Допущения: независимость задач, сопоставимость пар, t-приближение; совместная гарантия по всем осям не заявляется.
