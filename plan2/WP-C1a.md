## Цель
Модель запускает объявленную приёмочную команду обычным `run` — и получает ту же квитанцию, что дал бы `verify`, без
второго запуска «ради формы». Команды хоста и пользователя дают свидетельства вида сборка / typecheck / тесты.
Команда, которую модель сама сделала проверкой проекта, регистрируется автоматически с `Origin.Model`.
Сейчас: `run` объявленной команды квитанции не даёт; квитанции — только у `verify` и `QaDriver`
(`K/tool/verify/Verify.kt:354,412`, `K/verify/Scheduler.kt:85`); `Origin.Model` уже есть (`Verify.kt:359-360`,
`contract/Contract.kt:268`).

## Что сделать
1. **Распознавание до исполнения:** в `run` (`K/tool/run/`) команда сверяется с объявленными приёмочными командами
   контракта (`Acceptance.Run` с `origin !is Origin.Model` и команды хоста/пользователя): нормализованная команда +
   рабочий каталог. Совпало → исполнение через `Scheduler` со свежим штампом дерева → квитанция как у `verify`;
   результат `run` для модели — тот же вывод плюс строка квитанции. Не совпало — обычный `run`.
   Фоновый `run`/`wait` (A5) — квитанция по завершении; отмена — без квитанции.
2. **Виды свидетельств** сборка / typecheck / тесты для команд хоста и пользователя (ослабление D-50 одобрено
   владельцем): вид определяется объявлением или распознаванием инструмента; записывается в квитанцию; запись D-nn —
   в «Решения» (номер даст оркестратор).
3. **Команда модели как проверка проекта:** если модель запускает проверочную команду (тесты/сборка/typecheck), не
   покрытую объявленными, она регистрируется как проверка с `Origin.Model` автоматически (по умолчанию включено;
   флаг `Config` для отключения). Её квитанции — свидетельство «тест агента», **не** независимое: независимую
   приёмку не заменяют и обязательные проверки не ослабляют.
4. Схема/описание `run` в `ToolSchemas.kt` — только если нужна строка о квитанции (байты `[S]` меняются осознанно;
   обновить golden `LayoutTest`, записать в отчёт).

## Готово, когда
Объявленная приёмочная команда, запущенная через `run`, даёт квитанцию `Scheduler` со свежим штампом без второго
запуска; виды свидетельств записаны; команда модели регистрируется как проверка `Origin.Model`; L1/L2 зелёные.
